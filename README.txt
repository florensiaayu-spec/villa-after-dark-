VILLA AFTER DARK — PLAYABLE PROTOTYPE
======================================

Files:
- index.html: the playable prototype
- manifest.json: PWA metadata
- sw.js: service worker for offline caching when hosted on HTTPS

QUICK TEST:
1. Extract the ZIP.
2. Open index.html in a browser on a computer or Android device.
   (Some browser features such as installation/offline mode require HTTPS hosting.)
3. Choose dialogue options; relationship values, story flags, and logs update.

INSTALL AS AN APP (PWA):
1. Upload the extracted files to a static HTTPS host, such as GitHub Pages.
2. Open the hosted URL in Chrome on Android.
3. Chrome menu (⋮) > "Install app" or "Add to Home screen".
4. The icon launches the prototype in an app-like window.

IMPORTANT:
This is an early playable 2D visual-novel prototype with branching dialogue and local save data.
It is NOT yet a full 3D game, does not yet contain real 3D character animation or voice acting,
and is NOT published on Google Play. The external background image is optional and requires internet.
To publish on Google Play later, the project will need Android packaging, icon/splash assets,
testing, privacy disclosures if data is collected, and Play Console review.
